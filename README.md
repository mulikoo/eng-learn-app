# English Learning APP

REST API для приложения изучения английских слов. Позволяет пользователям тренировать лексику, получать подсказки (аудио, текст, картинка), а администраторам – управлять словарём.

## Возможности

- **Для обычных пользователей:**
  - Получение случайного слова для тренировки.
  - Проверка своего варианта перевода с обратной связью.
  - Три вида подсказок:
    -  Аудио (произношение слова)
    -  Текст (пример использования или синоним)
    -  Картинка (ассоциативное изображение)
- **Для администраторов / менеджеров:**
  - Добавление новых слов (с переводом, аудио, картинкой, текстовой подсказкой).
  - Редактирование существующих слов.
  - Удаление слов.

## Технологии

**Backend:**
- Java 21
- Spring Boot 3
- Spring Security (JWT-аутентификация)
- Spring Data JPA
- PostgreSQL
- Gradle

**Frontend (отдельный репозиторий):**
- HTML, CSS
- React.js

## Установка и запуск
Запустить docker-compose.yml
